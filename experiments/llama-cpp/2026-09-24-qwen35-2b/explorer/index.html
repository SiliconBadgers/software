Graph-derived work

All 24 text layers come from the real llama.cpp captures: 18 gated-delta recurrent layers and 6 attention layers. Shape expressions match the matrix MAC counts of all four captures exactly. Other prompt lengths and batches are analytical extrapolations.

Quantized modes remap the BF16 graph. W8/A16 means integer W8 × integer A16; W4/A8 means integer W4 × integer A8. Accumulation is INT32. Numerical quality, overflow handling and quantization accuracy are not validated here. Nonlinear math uses the selected vector/scalar cycle assumptions.

Timing model

Operations follow the captured serial schedule. Units cooperate within an operation. The overlap setting chooses either max(compute, shared-L1 service, HBM service), or their sum, plus launch overhead. This is a design estimate, not a cycle-accurate simulator.

GEMM uses padded array tiles and pipeline fill. GEMV support allows reduction-lane reuse when the token dimension is narrow. Recurrence respects sequential token updates; independent heads/sequences can run in parallel.

Memory & mapping

INT32 accumulator tiles and double buffering constrain matrix tiles. Weights reload for each token tile. Intermediates travel through shared L1. A configurable L1 share retains recurrent state. Other working sets beyond L1 incur an explicit spill proxy; bank efficiency approximates conflicts.

Missing vector primitives send the whole operation to the RISC-V software path. Requantization is fused if enabled on the matrix unit, otherwise it runs on vector or RISC-V. Dedicated recurrence owns a configurable scratch capacity.

What to calibrate

Replace assumed utilization, precision packing rates, scalar/software cycles, L1 efficiency and resource coefficients with RTL microbenchmarks and synthesis results. LUT/BRAM/URAM fit, routing congestion, timing closure, power, host I/O and multi-FPGA scaling are not modeled.
