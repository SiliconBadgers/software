# Software fixtures

Keep compact reference inputs, expected outputs and state cases here when shared across tests or studies. Record the originating model/format, dimensions, generation method and scope. Preserve enough information to distinguish exact expectations from tolerance-based comparisons.

The profiling experiment already preserves its own [input and output evidence](../experiments/llama-cpp/2026-09-22/README.md); link that evidence rather than duplicate large artifacts. A representative fixture should help another team investigate a kernel, state transition or interface without requiring full-model execution.

This directory currently contains this structure note. Members can add material when their chosen work needs it.

This is a suggested home for work supporting the [charter](../CHARTER.md) and
[objectives](../OBJECTIVES.md). The team can reorganize or extend it as its work
develops. A directory’s presence does not assign a task or require an artifact.
