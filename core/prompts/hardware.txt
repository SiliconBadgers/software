A weight-stationary systolic array computes a matrix product by loading one operand into a grid of processing elements and streaming the other operand through it. Each processing element holds a single weight, multiplies it by the activation arriving from its left neighbour, adds the result to the partial sum arriving from above, and passes both values onward on the next clock cycle. After a fill latency equal to the sum of the array's row and column counts, one finished output row emerges every cycle, so utilization approaches one hundred percent for large matrices but drops sharply when the output dimension is smaller than the array width. This is why matrix-vector products during single-token decoding use such an array poorly unless the design adds a reduction mode that spreads the vector across rows. Quantized weights add a further constraint: four-bit values are packed two to a byte, each group of sixty-four shares one scale factor, and the accumulator must be wide enough to sum thousands of products without overflow. The memory system then has to deliver weights at the rate the array consumes them, which for a decode step that touches every parameter once is set by external bandwidth and not by arithmetic throughput.
